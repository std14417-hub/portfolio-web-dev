เกี่ยวกับผม

ผมชอบลองสร้างเครื่องมือจาก ปัญหาที่เจอจริง ตั้งแต่ช่วยทำซับวิดีโอและค้นข้อมูล ไปจนถึงระบบตรวจจับภาพจากกล้องและอุปกรณ์ IoT ผมจะเริ่มจากทำต้นแบบขึ้นมาลองใช้ แล้วดูว่ามันช่วยได้จริงแค่ไหน ตรงไหนยังผิดพลาด และควรแก้อะไรต่อ

ในโปรเจกต์ต่าง ๆ ผมได้ลองใช้ Python, Local LLM, Whisper, RAG, YOLOv8, ESP32 และ API ตั้งแต่ต่อเครื่องมือหลายตัวให้ทำงานร่วมกัน ไปจนถึงทดลองกับกล้องและเซนเซอร์ รวมทั้งดูข้อจำกัดและค่าใช้จ่ายก่อนคิดจะนำไปใช้จริง

อีกส่วนหนึ่งคือช่อง YouTube KAO TH1 ที่ผมดูแลเอง ตั้งแต่หาข้อมูลและเขียนสคริปต์ ไปจนถึงตัดต่อแล้วลงคลิป การทำช่องทำให้ผมได้ลองดูผลตอบรับจากคนดูจริง และมองเห็นงานบางอย่างที่น่าจะทำให้สะดวกขึ้นด้วยเครื่องมือของตัวเอง
